# 智能客服机器人工作流程

## 一、系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    智能客服机器人系统                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌──────────────┐    HTTP    ┌──────────────┐              │
│  │   前端/客户端  │ ─────────→ │   FastAPI    │              │
│  └──────────────┘            │    Server    │              │
│                              └──────┬───────┘              │
│                                     │                       │
│         ┌───────────────────────────┼─────────────────────┐ │
│         ▼                           ▼                     ▼ │
│  ┌─────────────┐          ┌─────────────┐       ┌───────────┐│
│  │ Agent State │          │ Qianwen LLM │       │ Memory    ││
│  │ (会话状态)   │          │   (千问模型) │       │ (关键词记忆) ││
│  └─────────────┘          └─────────────┘       └───────────┘│
│         │                           │                     │   │
│         └───────────────────────────┼─────────────────────┘   │
│                                     │                       │
│                                     ▼                       │
│                              ┌──────────────┐               │
│                              │  Mock Data   │               │
│                              │ (业务数据库)  │               │
│                              └──────────────┘               │
└─────────────────────────────────────────────────────────────┘
```

## 二、核心工作流程

### 1. 会话创建与管理流程

```
用户发起请求
    │
    ▼
检查 session_id 是否存在
    │
    ├── 存在 ──→ 获取现有 AgentState
    │
    └── 不存在 ──→ 创建新 AgentState (生成 session_id)
            │
            ▼
        存储会话状态
```

### 2. 消息处理流程

```
用户发送消息
    │
    ▼
┌──────────────────────────────────┐
│  Step 1: 记忆用户问题             │
│  - 提取关键词                     │
│  - 存储到 Memory 模块             │
└──────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────┐
│  Step 2: 检索相关记忆             │
│  - 根据关键词搜索历史问题          │
│  - 构建上下文信息                 │
└──────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────┐
│  Step 3: 构建完整 Prompt          │
│  - 历史对话记录                   │
│  - 相关记忆信息                   │
│  - 当前用户问题                   │
└──────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────┐
│  Step 4: 调用千问模型             │
│  - 发送请求到 DashScope API       │
│  - 获取 AI 响应                   │
└──────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────┐
│  Step 5: 更新会话状态             │
│  - 添加用户消息到历史             │
│  - 添加 AI 响应到历史             │
│  - 保存会话状态                   │
└──────────────────────────────────┘
    │
    ▼
返回响应给用户
```

### 3. 业务数据查询流程

```
用户查询业务数据
    │
    ▼
路由匹配 (/api/*)
    │
    ├── /api/customers ──→ 查询客户数据库
    ├── /api/products  ──→ 查询产品数据库
    ├── /api/orders    ──→ 查询订单数据库
    └── /api/categories ─→ 查询分类数据库
            │
            ▼
        返回 JSON 数据
```

## 三、API 接口汇总

### 会话管理接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/chat` | POST | 异步聊天（自动维护会话） |
| `/chat_sync` | POST | 同步聊天 |
| `/session` | POST | 创建新会话 |
| `/session/{id}` | GET | 获取会话详情 |
| `/sessions` | GET | 列出所有会话 |
| `/session/{id}` | DELETE | 删除会话 |

### 记忆管理接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/memory/keywords` | GET | 获取所有关键词 |
| `/memory/search` | GET | 按关键词搜索 |
| `/memory/session/{id}` | GET | 获取会话记忆 |

### 业务数据接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/customers` | GET | 获取客户列表 |
| `/api/customers/{id}` | GET | 获取客户详情 |
| `/api/customers/{id}/orders` | GET | 获取客户订单 |
| `/api/products` | GET | 获取产品列表 |
| `/api/orders` | GET | 获取订单列表 |
| `/api/categories` | GET | 获取分类列表 |

## 五、使用示例

### 1. 开始新对话

```bash
curl -X POST http://localhost:8000/chat_sync \
  -H "Content-Type: application/json" \
  -d '{"prompt": "你好，我想咨询一下产品"}'
```

### 2. 继续对话（使用 session_id）

```bash
curl -X POST http://localhost:8000/chat_sync \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "笔记本电脑有哪些型号？",
    "session_id": "5b9bf4ed-3f76-4051-82c5-4e4cffe5c0a6"
  }'
```

### 3. 查询客户信息

```bash
curl http://localhost:8000/api/customers/C001
```

### 4. 查询客户订单历史

```bash
curl http://localhost:8000/api/customers/C001/orders
```

### 5. 搜索产品

```bash
curl "http://localhost:8000/api/products?keyword=耳机"
```
